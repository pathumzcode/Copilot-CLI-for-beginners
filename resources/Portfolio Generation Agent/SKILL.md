# Portfolio Generation Skill

## Purpose

This skill provides detailed instructions for creating and improving professional, responsive developer portfolio websites using verified CV or profile information.

The skill should be followed by the Portfolio Generation Agent during portfolio-generation tasks.

---

# 1. Analyze the Input

Before creating the website, analyze the provided CV, resume, or profile information.

Identify available information such as:

- Name
- Professional title
- Professional summary
- About information
- Education
- Programming languages
- Technical skills
- Frameworks
- Databases
- Cloud technologies
- Data Science skills
- AI/ML skills
- Development tools
- Projects
- Certifications
- Experience
- Achievements
- Contact information
- GitHub
- LinkedIn
- Other professional links

## Accuracy Rule

Never invent personal information.

Never invent:

- Qualifications
- Certifications
- Employment
- Experience
- GitHub repositories
- Project results
- Achievements
- Technical skills

If information is missing:

- Use a reasonable placeholder only when appropriate.
- Otherwise ask the user.
- Clearly identify unclear information.

The CV should be treated as the primary source of personal information.

---

# 2. Inspect Existing Projects

If an existing portfolio project is provided:

1. Inspect the project structure first.
2. Identify the technology stack.
3. Inspect existing pages and components.
4. Inspect CSS and JavaScript.
5. Inspect assets.
6. Understand existing functionality.
7. Identify reusable components.

Do not immediately replace the project.

Preserve useful existing functionality.

Do not unnecessarily change the project structure.

Do not delete important files without approval.

---

# 3. Website Design

Create a modern and professional developer portfolio.

The design should provide:

- Clean layout
- Strong visual hierarchy
- Responsive design
- Modern typography
- Professional navigation
- Attractive hero section
- About section
- Skills section
- Projects section
- Education section
- Certifications section
- Experience section when available
- Achievements section when available
- Contact section
- Footer

Only create sections supported by the user's information when appropriate.

Do not create empty or misleading sections.

---

# 4. Visual Style

Use a professional technology-oriented visual style.

Recommended characteristics:

- Modern UI
- Professional spacing
- Clear typography
- Consistent design system
- Subtle animations
- Cards
- Gradients where appropriate
- Glass effects only when they improve the design
- Professional icons
- Responsive navigation
- Mobile-friendly layouts

Do not make the design unnecessarily complicated.

The design should support the content instead of distracting from it.

---

# 5. Hero Section

The hero section should clearly communicate:

- Name
- Professional title
- Short introduction
- Primary call-to-action
- Secondary call-to-action
- Profile image when available

Possible CTA buttons:

- View Projects
- Download CV
- Contact Me

Only include actions that can actually work.

Do not create a Download CV button unless a CV file or valid CV URL is available.

---

# 6. About Section

Create an About section using verified information.

The section can include:

- Professional summary
- Educational background
- Areas of interest
- Development focus
- Career interests

Do not exaggerate the user's experience or qualifications.

---

# 7. Skills Section

Group skills logically.

Possible categories include:

- Programming Languages
- Web Technologies
- Frameworks
- Databases
- Cloud
- Data Science
- AI/ML
- Development Tools

Only include skills supported by the user's CV or provided information.

Avoid inventing proficiency levels.

Do not create arbitrary percentages such as:
